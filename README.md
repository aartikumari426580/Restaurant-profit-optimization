\# Predictive Modeling and Profit Optimization for Multi-Channel Restaurant Operations



\## Project Overview

This project focuses on analyzing restaurant operations and predicting monthly net profit using Machine Learning. It evaluates multiple sales channels, including in-store, Uber Eats, DoorDash, and self-delivery.



\## Objectives

\- Analyze restaurant business performance.

\- Perform Exploratory Data Analysis (EDA).

\- Predict total monthly net profit.

\- Compare Machine Learning models.

\- Optimize restaurant delivery channel strategies.

\- Visualize business insights through an interactive Streamlit dashboard.



\## Technologies Used

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Scikit-learn

\- Streamlit

\- Plotly

\- Joblib



\## Machine Learning Models

\- Linear Regression

\- Random Forest Regressor

\- Gradient Boosting Regressor



\## Dataset

SkyCity Auckland Restaurants \& Bars dataset.



\## Project Structure

\- app.py – Streamlit dashboard

\- data/ – Dataset files

\- models/ – Trained ML models

\- notebooks/ – Analysis notebooks

\- reports/ – Project reports

\- src/ – Source code

\- tests/ – Testing files

\- requirements.txt – Dependencies



\## How to Run



Install dependencies:



```bash

pip install -r requirements.txt

```



Run the application:



```bash

streamlit run app.py

```
